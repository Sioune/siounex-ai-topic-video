# A2 冷银舞台与往期精选模板

此处保留早期A2规则与可运行源码。2026-10-10后续统一背景、章节揭亮和filmstrip版本优先遵循 [统一舞台与连续叙事](unified-narrative.md)；不要把本A2持续轮播、框壳及4秒停留直接套回新机制，也不要声称此旧源码已实现新组件。

## 获批范围与状态

用户于2026-10-10批准冷银 A2 整体布局及往期轮播样片，要求用于完整版并收敛为可复用模板。批准的是视觉方向和样片，不等于后续整片最终验收。实际渲染器、示例配置、字幕时轴、素材登记及 SVG/PNG 已收入 assets/a2-runtime/；assets/a2-silver-history.template.json 保存可复用规则与入口。两个原始 ZIP 的 Library ID、版本、字节数与 SHA-256 已登记到 assets/resource-manifest.json 的 a2_silver_history_template。

Windows 已将两个 ZIP 恢复到新目录，完成 --check 与90帧 --smoke；恢复结果一致，与已交付成片开头 SSIM 为0.999946。源码包成员已在云端逐一验证 SHA-256 后原样集成。本次技能集成不渲染视频。完整模板命令、新选题全流程和 Mac/Linux 尚未验证；原本8.966秒无声样片的技术QA与后来源码测试分别记录，不混为同一验收。

## 布局与视觉层级

- 沿用获批冷银科技质感舞台背景，处理过大的空白，保持清爽、克制；不要另造视觉方向。冷银不代表任意改成高亮闪烁、粒子或强发光背景。
- 将主素材作为最主要的信息层。横屏先完整等比适配，建立连续全局；随旁白重点平滑聚焦，讲完回全局，遵守已有放大倍数、源分辨率及真实信息关系的检查规则。
- 保留独立、清晰、手机可读的字幕。往期模块放在下方，不能侵入字幕安全区、遮挡主体或抢走旁白重点；标题、封面和看点需同属真实往期内容。核心信息仍避开平台底部安全区。
- 展示真实往期封面、对应标题和简短看点，以纵向轮播切换；禁止虚构往期、错配封面与文案或拿占位卡当成正式内容。没有可用真实资源时说明缺项，不生成冒充往期的素材。
- 本次已批准小样采用停留4秒、缓动切换0.8秒，作为此模板起始参数保留；不是所有视频都必须同样节奏。实际工程已恢复：smoothstep 缓动，开头静止6秒；关键数字及末尾问句有保护区间。示例的绝对时间只适用于该旁白，新片按实际字幕时轴重算。精确坐标、字号、颜色及循环接缝以真实配置和渲染器为准。切换持续时间与静止停留时间分别计量，检查长标题能否读完、循环首尾是否自然、字幕全程独立。
- MP4中的封面仅是画面内容，不可点击；不要加假按钮、假点击反馈或声称点击封面可跳转。确需平台链接时另按真实平台能力和授权配置。
- 当前这条完整版仅放往期，隐藏下期预告。以后只有下一期确已确定且标题/素材真实齐备时才启用预告；资料缺失默认隐藏，不能预设、编造或用空白占位。
- 保留反向明暗选择的原版独立4秒品牌片尾、原文案、标识、速度与原音轨。正文音乐在片尾前结束，不给片尾叠音乐，不把往期轮播延伸覆盖原片尾。不要为配合冷银背景重做或改色片尾；按实际正文背景明暗选择既有版本。
- 正式版及审阅版都不新增审片角标、版本号、工具/技术标签或其他未要求的水印；遵守原素材权利标记与已批准品牌元素规则。

## 参数与恢复接口

1. 读取 assets/a2-silver-history.template.json、assets/a2-runtime/render-config.json、asset-registry.json 与 render-a2.mjs。后者是 Claude 示例：文案、旁白对齐、保护区间、素材、审批字段和片尾选择不可直接视为新片事实或许可。新片必须另核实际稿本、声轨、来源和授权。
2. 在当前有授权的目标环境复制 assets/a2-runtime/ 到新项目目录，或从 Library 物化两个 ZIP，核对资源索引 SHA-256 后解压到同一受控目录。媒体包补齐 example-inputs/；不要改原技能内的示例或覆盖历史项目。历史电脑路径不是访问授权。
3. 准备 Node、FFmpeg/FFprobe（drawtext 与 libass）。已验证环境为 Windows、Node v24.14.0、FFmpeg 8.1.1。Microsoft YaHei 与 Segoe UI Semibold 字体未分发；在目标系统核实际字体路径/校验值。换字体或平台必须检查字宽、换行与手机可读性，不能只改路径就声称等效。
4. 在项目目录运行 node render-a2.mjs render-config.json --check；再运行 node render-a2.mjs render-config.json --smoke 输出90帧。完整命令为 node render-a2.mjs render-config.json，但此通用命令尚未实际验证。当前技能更新只登记这些命令，不自动发起渲染。
5. 将新片正文绑定为30fps连续帧序列及完整源面，替换真实声轨母版、字幕对齐、标题、真实往期封面与对应标题/看点、来源及SHA。保持主源面完整，不用旧配置裁新素材；新旁白的重点区间、全局/聚焦关系需另安排。示例渲染器是合成器，不自动创作旁白或计算新的聚焦镜头。
6. 片尾接口使用原版4秒的1080×1920、30fps、120帧规范化视频；保留原版视觉设计及原音轨，只做必要技术规范化，不重做设计。音轨母版需含对应片尾原音轨，不能把正文旁白或音乐拖进片尾。示例为浅色正文配深色片尾；未来仍按实际背景反向选择既有原版。
7. 当前渲染器强制 next_episode.visible=false。未来即使下一期已确定，也须先补真实预告实现并审阅，不能只开开关；缺资料时始终隐藏。保留事实核验、封面/宣发、发布后复盘及授权规则，不自动付费生成、配置凭证、长期监控或公开发布。

## 复用验收

使用恢复的源工程先输出静态图与短动效，再按获批样片比对原尺寸和手机尺寸；已有方向不无故重设计。检查主画面完整、全局/聚焦/返回对应旁白、字幕可读且无覆盖、往期缓动不抢注意力、真实封面标题看点一致、无伪点击、无下期占位、无多余标签。完整版仍必须重新执行全片解码、音频检查与真实播放；8.966秒无声小样不能证明完整版音画或片尾通过。核查独立4秒原版片尾及其原音轨，无额外音乐叠加。不能把用户喜欢样片当作技术QA完成。
