# Executable production principles

制作与验收强制要求：本人旁白以1.15作为利落、有精神的参考，先确认原音频已有处理速度；当前完整实测正文音轨加固定原片尾及其他占时为60<T≤70秒时，不额外缩稿，可有依据地仅正文口播保音高额外提速，累计速度允许超过旧1.25／1.3默认上限并如实记录，不盲叠；T>70秒才缩稿，最终完整导出仍须≤60秒。原v5片尾全部119帧、1×原速与完整原声保留，BGM不随正文提速。保音高调速，删除无意义额外停顿，依实际词级时间重对齐字幕、镜头与嘴型。自然、完整断句和尾字优先；未真实试听不得称听过。往期默认最近已发布三期；按本次明确授权名单锁定真实历史ID及实际发布原标题，逐字保留，不改为简称。完整标题优先单行，放不下须改布局或完整换行，不缩成小字、不省略、不截断；章节完整可见，推荐标题/说明/封面间距有层级，并核验手机尺寸实际导出。保留已有模板的贯穿分隔渐进蒙版章节进度、本期缩略图与真实进度、和往期卡片同槽轮换，不能擅删组件或整套重设计。实演必须正常速度；原始FPS与输出FPS转换保持相同经过时间，不慢放/循环/重帧凑旁白。记录每段原片SHA、入出点、输出帧范围、倍速及相邻重复帧审计，对照实际导出源区域。剪去等待需明确说明，不能伪造零延迟。机器检查通过不等于审美、听审、版权、付费或发布批准。
