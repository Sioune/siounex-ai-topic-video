# 发布服务桥接：只读接入

本阶段只验证独立服务认证和读取现有发布资料，不是完整发布执行器。

## 安全配置

- 在 Replit 的 Secrets 中配置 `SERVICE_TOKEN`，使用至少 32 字符的高强度随机值；建议 32 随机字节的 base64url 或十六进制形式。
- 在调用端的安全密钥配置中填写同一个值。不要放进聊天、代码、URL、日志或浏览器前端。
- 更新 Secrets 后重启开发 API；线上站点需要发布包含这些接口的版本，配置密钥本身不会更新线上代码。
- 只允许 HTTPS 机器请求。浏览器 Origin / Sec-Fetch 请求会被拒绝。普通 `/api/*`、MCP 仍要求站主的 Clerk 登录。
- 轮换 `SERVICE_TOKEN` 会撤销旧值。该令牌本阶段只有只读权限。

## 接口

所有请求使用 `Authorization: Bearer <SERVICE_TOKEN>`，禁止把令牌放在查询参数中。

| 方法与路径 | 返回内容 |
| --- | --- |
| `GET /api/v1/publishing` | 当前只读能力。200 只表示令牌通过，不表示 Codex、平台登录或发布执行器在线。 |
| `GET /api/v1/publishing/tasks?state=ready&cursor=...` | 当前站主已有浏览器发布待办中，排队且账号可发布的摘要；每页最多 25 条，游标不含凭据。沿用原发布队列最多 200 条待办的读取窗口，并在响应的 `source_window_limit` 明示。 |
| `GET /api/v1/publishing/tasks/{id}/package` | 当前待办的已审宣发、封面/视频校验信息和选项；重新校验账号、任务归属、当前计划及确切已审版本。返回元数据，不提供通用私有文件下载能力。 |

列表不是新的发布授权。包撤回、计划暂停、版本变化、账号不可用或任务被领取后，包读取会拒绝。服务不能指定 `owner` / `owner_id` 来切换数据归属。

未配置有效密钥返回 503；令牌缺失或错误返回 401；非 HTTPS 或浏览器请求返回 403。所有响应不缓存。

## 未启用的能力

领取、续租、事件、回执、媒体下载和指标写入尚未开放；写入方法返回 405。不能据此声称三端接驳草案已全部实现，也不能把读取资料当作发布授权。

下一阶段需要单独接入任务级租约、幂等操作和真实平台回执验证，保留站主决定以及已批准文件的版本/hash 绑定。
