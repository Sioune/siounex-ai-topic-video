# 品牌与独立4秒片尾

品牌：怎么用好AI。口播：关注我，AI有新招，用起来才重要。
六项服务：实战培训、战略诊断、产品共创、经营陪跑、内容生产、工具方法。
了解品牌内容时可参考用户网站的 /zh/services、/zh/insights、/zh/projects、/zh/ai-products；这些是相对路径，需要已验证网站来源，不能拼猜域名。

片尾只展示服务能力，不放具体产品截图，不引流个人网站，不显示网址、二维码或伪造的平台原生操作控件。获选模板中的品牌自有“关注我”装饰CTA保留，不将它冒充微信等平台系统按钮，也不承诺可点击。

直接复用已经做好的深/浅版独立4秒关注品牌片尾，按主视频背景选择相反明暗：深色正文用既有浅色片尾，浅色正文用既有深色片尾。两套已有成片，不为每条视频重做，不把某一版改色或另造变体冒充另一版。若正文混合明暗，按靠近片尾的主体背景及全片基调判断，仍不明确时询问，不擅改品牌资产。先按资源索引恢复对应原文件；确实无法恢复时明确缺哪一版并请求原文件，不因“找不到”自行新做。只有用户明确要求修改或重制后才进入该范围。

已批准深浅双方向：
- 中心圆形本人数字人，渐变光环与轻轨道，左右各三个错落服务词。
- 品牌字最大；顶副标题“让AI真正用起来”为约26px放大胶囊。
- 六个服务词0.4秒内入场，随后保持稳定可读。不要做成六矩形组织架构图。
- 深版蓝紫青；浅版灰白深蓝。固定反向明暗映射为“深色正文→浅版”“浅色正文→深版”，不是所有项目固定同一版；资产身份以 assets/resource-manifest.json 中对应角色和Library ID为准。
- 片尾独立4秒。按语音实际时间调整出现顺序但不吞尾字。保留深浅可复用版本、独立片尾文件和拼接的完整视频。

assets/outro-dark.svg 和 assets/outro-light.svg 是获选布局的轻量模板；其中肖像以外部 portrait-source.jpg 引用，按已授权当前肖像替换。模板不含本人声纹和视频，应先从资源索引恢复当前批准素材。SVG不是已经渲染的视频。

## 拼接与导出核验
- 原样保留获批片尾的品牌文案、标识、关注装饰、4秒时长和音轨，不随正文旁白倍速、换声、改色或重绘。SVG只用于追溯布局，不能替代找不到的现成片尾。
- 在实际导出的完整视频中检查正文末段、片尾入点及稳定帧，确认真实画面形成“深→浅”或“浅→深”对比，而非只看文件名；复核接点无错误旧尾、重复片尾、额外角标、音轨断裂或吞尾字。对照原片尾身份和时长，不凭编辑器预览就宣称正确。
