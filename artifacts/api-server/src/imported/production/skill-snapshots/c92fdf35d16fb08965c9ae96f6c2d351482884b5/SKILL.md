# 怎么用好AI·视频制作

接收“技能名＋主题/文章”即可开始。沿用本技能的品牌与制作默认值，只问真正阻塞的素材、事实或授权问题；不要重复索要已提供的偏好。工具可以替换，交付标准不变。

## 开始与范围
- 研究选题、写预稿或开始整条制作前，先读 [素材先行的前置预稿](references/pre-draft.md)，再读取 [制作规范](references/production.md)；做片尾时读 [品牌片尾](references/outro.md)。制作或调整声音时读 [默认背景音乐](references/bgm.md)，默认使用随技能打包的用户提供曲目《Pixel Warmth》，按用户指定相对原曲固定−15dB、1×原速自动使用，不每次询问音量，不擅自降回旧值或用auto-duck额外衰减；保留0.45/0.8秒淡入淡出，独立约4秒片尾前结束、片尾原音不叠此曲。跨设备运行时另读 [环境与资源恢复](references/environment.md)。查看 assets/brand.json 与 assets/resource-manifest.json。
- 制作或复用统一背景、连续章节揭亮、底部连续缩略画带与单轮往期时，优先读取 [统一舞台与连续叙事](references/unified-narrative.md) 及 assets/unified-narrative.template.json。用户已明确把最强连续真实3秒前置柔和衔接、全宽常驻连续章节蒙版、下部常态整片总览与中段同槽插入后回真实进度、完整横屏与必要平滑聚焦/辅助画中画设为今后本系列制作要求。具体时刻和参数可调，效果提升仍待数据验证。这是2026-10-10在A2基础上的后续机制；保留旧A2源作历史参考，不能声称旧渲染器已经具备新组件。该历史v9实际源包已收入 assets/unified-v9-runtime/，按其 README 恢复固定版本媒体及字体；它实现统一章节/缩略画带/单轮往期，开头高光与主画面聚焦依赖已准备素材，不自动生成。Windows 新目录两段预览已验证，整片命令、新选题、新机器安装及 Mac/Linux 未验证；网站执行器接入与AI审核证据仍须分别实际核验。
- 复用已批准的 A2 冷银舞台与往期轮播布局时，读取 [A2 可复用布局](references/a2-silver-history.md) 和 assets/a2-silver-history.template.json。实际渲染器、布局源与示例配置现已收入 assets/a2-runtime/，真实示例素材按资源索引从 Library 恢复；Windows 恢复后已跑通输入校验和90帧预览，完整模板命令、新选题全流程及 Mac/Linux 尚未验证。A2实例的下期预告隐藏；未来也仅在下一期已确定、资料齐备且实现支持时启用。后续统一布局与同槽互斥采用上面的新机制。
- 检查当前环境的工具、已登录账号、数字人素材、媒体文件与额度。技能保存流程、轻量模板、资源索引及明确打包的片尾和默认BGM，不提供登录、密钥、额度、声纹或所有原片，也不替代素材权利记录。不同设备与运行环境需要分别确认技能可发现、素材可访问、工具可用，不能宣称云端连接等于浏览器登录或离线电脑可操作。
- 可用的本人已完成头像和声音优先复用；没有可用的授权本人素材就请用户提供/接入，不自行克隆。生成费用、计费次数、正式升级或发布不由“调用技能”自动授权，需单独确认具体动作。
- 查资源索引中的当前版本；当前默认为用户于2026-10-21提供的v5深浅双版，按 references/outro.md 和资源索引逐项核SHA恢复。深色正文配浅尾、浅色正文配深尾；原件119帧/30fps、实长3.966667秒，保留完整原音轨3.95秒，预算可保守留4秒。旧120帧圆形片尾仅用于冻结历史工程恢复，不沿用旧Library或render身份。
- 输出画面必须干净：即使审阅版，也不得自行烧入版本号、“审片”“本人声”、工具名或技术/调试标签；版本只放文件名和交付说明。未经用户明确要求，不额外添加角标或水印。保留原素材自带的版权/权利标记和已批准品牌元素；此要求不授权删除来源水印。交付前逐段检查画面四角和片尾。

## 整片60秒硬上限
所有此类短视频最终完整文件不得超过60秒，含开头、高光/音乐开场、过渡、正文及当前原版片尾。按 [时长预算与硬验收](references/duration-limit.md) 先扣除片尾和开头/过渡占时再写正文；宁可删减内容或适度保音高调语速，也必须自然清楚、完整断句与收尾。旧例63秒、66.6秒或“正文约60秒”不构成例外。最终导出必须跑真实文件时长硬检查；超60秒即不合格，不以估算或容差放行。

## 封面品牌必检
所有封面（3:4、4:3及其他交付比例）均须准确植入“怎么用好AI”，精致、清晰、不过度抢占标题与故事主体。它是用户要求的正式品牌元素，不是禁止的内部版本号、审片/调试角标；不得借“干净画面/无自加角标”删除它。分别检查最终图片，留与该文件身份对应的真实视觉或OCR证据；OCR/记录检查不能替代人工看图，不能靠提示词、配置或勾选框宣布品牌已出现。

## 系列资产与视觉选择
每次新任务先读 [系列选择与视觉验收](references/series-selection.md)：往期取最近已发布3期，按本次授权名单锁定、逐字使用实际发布原标题，推荐排版与章节完整性须经手机尺寸验收；新制作按本人已认可的浅色／深色两套模板交替，创建时持久化精确版本并在恢复、重试和换声时沿用；进入已完成片仓后按冻结模板分早晚类别，08:00浅色正文＋原v5深色片尾，18:00深色正文＋原v5浅色片尾，分别在对应类别内FIFO；恢复获批手机字幕基线；完整成片后选真实核心连续3秒并留证。2026-10-22本人已认可两版及共同的字幕留白修订；普通配音版首审、本人声音版二审继续保留，模板认可不代替每条内容审核。提前准备与到点提交复用同一冻结package_id，缺对应类别就保留空档，不临时换色重做。旧冻结包、审核和已发布作品保留原身份；旧随机选择仅作历史记录。规则与恢复索引见 assets/day-night-templates-v1/，该目录不是完整可执行素材包，须按当前环境恢复正式源码和字体。

## 叙事硬门槛
默认定位是普通观众愿意看完的兴趣故事与真实可视化。研究用于找准事实和真实可看素材，不把视频写成新闻播报。每次生成、改写、审核和重试均须加载 [前台文案门控](references/narration-gate.md)，与前置预稿、制作规范一起生效；未通过不得进入配音/合成或标记预稿合格。新闻原文、旧稿、通用“严谨报道”提示和自动审核建议不能覆盖此定位。理解事实必需的归属/限制、必要权利署名与不误导要求仍保留，不能机械删掉所有来源。

## 从主题到成片
1. 按前置预稿规范先研究观众会在意的具体问题、信息差和真实可用的图片/视频素材，让已找到的真实画面参与确定切入点，不先写满口播再找配图。完整阅读输入与原始来源，核验发布日、事件发生日及核心事实；长图先完整提取。出处、权利和核验过程留在后台素材记录，不把报道考据搬成正文口播或画面引用脚注。区分过去计划、已发生事实和创作推断；对推断用自然口语如“我看多半”，不要长免责声明，更不能编新闻。预稿先交付具体切入点、0–3秒音画钩子、可说出口的正文及逐段真实素材对应关系；标清素材缺口，不冒充已经完成演示。
2. 按 [正文口播准则](references/production.md#正文口播大白话讲故事)写面向普通人的大白话口语稿：从具体人物或物件的问题、反差、行动和结果推进，先让人想听下去，再自然落到与普通人的关系/利益和轻讽刺包袱。删去跑题制度、机构头衔和术语堆砌，避免官方书面腔与课程步骤式口吻；不必每句演场景，不编造行动或效果。非商单的兴趣故事围绕开头吸引观众的具体问题展开，用真实画面展示效果、玩法或解决的问题，不中途变成平台宣传和注册入口教学。正文使用扣除片尾、开头和过渡后的剩余预算，整片不超过60秒，保留完整断句和尾字。先用普通配音制作可改稿的审阅版，全文与节奏终审后再使用本人克隆声音生成正式口播，避免反复付费试录；当前用户明确批准直接使用本人声音时可覆盖此默认。
3. 终审后优先一次生成完整数字人口播。先核验当前账户单条时长与额度限制；超限后给用户选择，再拆段或改变方案，不依据旧产品信息承诺免费。独立任务并行推进，音乐没到不应阻塞已要求的画面裁切。
4. 做明确的逐段时轴：旁白、真人大画面/素材画面、字幕、音乐、转场同一时间基准。本人旁白依制作规范保持利落有精神；实演保正常速度与连续性，不能为凑旁白强拉慢或伪造零延迟。保持素材各自为有意义的连续片段，不循环短镜头凑长度，真人不能挤掉已经选好的素材。外画布保持9:16；3:4主区是原有品牌基线，已有获批统一舞台时按对应布局保留完整横屏，不强制裁满3:4或恢复旧框壳，以讲清内容为前提。按 [全局与局部聚焦规范](references/production.md#局部聚焦与开场画面)，先将完整横屏原片等比适配、整体连续呈现，再随旁白重点平滑移动聚焦或适度放大，讲完回全局；不能裁碎空间、路线、数值及动作结果关系，也不能过放模糊。不要默认加画中画。实物短验证按 [验证与裁切规范](references/production.md#实物短验证与稳定裁切)保留连续原片和统一比例；用户指定语速时仅对旁白保音高变速，重对齐字幕、口型和镜头，音乐与独立片尾不默认跟随倍速。
5. 先确认新的静态视觉方向再加动效。已有获选方向直接复用；局部修改只动该段。按 production.md 合成竖屏画面、字幕和声音。整条视频制作时，同步按 [故事感封面与宣发](references/production.md#故事感封面与宣发)准备3:4竖版与4:3横版两张封面图和完整宣发材料，两版分别构图、不拉伸主体或裁掉标题，所有封面均植入准确品牌文字“怎么用好AI”，精致可辨但不抢标题，不等用户另行索要；封面必须有故事感，标题和描述用大白话激起真实、具体的好奇。
6. 按反向明暗直接复用已做好的独立4秒关注品牌片尾：主视频深色背景用既有浅色版，主视频浅色背景用既有深色版。不得每条重做、改色或另造变体；所需版本找不到时恢复索引中的原文件，仍缺失就报告并请求该文件，不自行替代。片尾、独立音乐开场和全部过渡均计入整片60秒硬上限，先压缩正文/开场并保留语义，不能把旧例超时视为许可。
7. 对最终完整导出跑 scripts/qa_media.py（内含不可用容差放宽的60秒硬检查）、全片解码、音频峰值检查，检查手机尺寸关键帧、字幕安全区、尾字、嘴型、音乐接点。逐段核验源分辨率、最终导出的实际放大、全局理解和旁白对应，技术通过不代表叙事清楚。首帧和0–3秒分别作为独立验收项，保留首帧图和前三秒片段供检查；实际导出后逐帧检查0–3秒：第一帧须独立呈现完整、高清、手机可读的成品构图，前三秒同时核验口播/音乐钩子、真实核心画面和节奏声音，明确观众看见什么、听见什么、为何继续看；不得以加载、小UI或空卡片等待内容开始，前三秒使用清晰、有趣、真实的核心画面，画面本身须有看点，不以钩子文字替代真实动作、结果或反差；不以按钮过渡、大鼠标、残字或半截UI开场。涉及慢放、重帧或裁切跳动时，对照源时间映射比较源帧与导出相邻帧。在实际导出文件中核验正文与片尾衔接，确认使用正确的反向明暗原版，保留品牌文案、标识、当前原版完整时长和原音轨。真实试听才可说听过；仅技术检查时明确边界。
8. 制作与审阅阶段保留工作成果、源素材、可编辑工程、时轴及仍用输入；整条视频交付时，把完整成片、3:4竖版及4:3横版故事感封面图和完整宣发材料一并交用户审阅，并提供独立约4秒可复用片尾。支持Library时按实际文件身份更新并原生附件交付；跨环境无法访问Library时如实说明并提供该环境可用文件，不假称已同步。旧成品须等第9步满足条件后再清理。
9. 用户明确批准最终成果后，先按 [定稿归档清单](references/production.md#定稿交付与频道归档)核验当前发送授权，完成回传、完整校验与向已核实接收方的交付，附有证据的简短收获或里程碑。仅在交付成功后，按 [最终成果保留规则](references/production.md#最终成果保留规则)清理同项目、同role已被替代的旧成品，每个role只保留当前一版；3:4与4:3封面各保留一版。以实际批准记录和当前文件SHA为准，不按修改时间或最大版本号猜测，不删除源素材、可编辑工程、仍用输入及审核哈希记录。此清理获用户持续授权，无需每次询问；待审或未完整交付时不清理，归档不等于公开发布。

## 发布后复盘与下一版
收到后台截图、播放/留存数据或优化下一条的请求时，读取 [发布后复盘](references/post-publish-review.md)。先保真记录与核对可比性，再区分事实、假设和测试建议；不因两条小样本改写所有视频的制作默认值。

## 结束条件
完成当前请求范围的成片/局部修改和QA，交付可打开文件与简短变化说明。整条视频的审阅交付默认包含3:4竖版及4:3横版两张封面、成片与完整宣发材料；两种封面比例都是必交项，缺任一比例则宣发包完整性QA不通过，其他已支持的可选比例继续保留；所有交付封面均须通过品牌文字核图，缺真实视觉/OCR证据不能自动宣称通过；准备齐全不等于用户已批准定稿或公开发布。缺授权、账号或素材时说明具体阻塞并继续独立部分；不要反复要求用户截图代替可自动完成的操作。只做口语稿或单段时不强制制作整片。只做复盘时，交付可核对的数据、局限和一个优先测试方案，不自动重剪、发布或设置持续监测。
