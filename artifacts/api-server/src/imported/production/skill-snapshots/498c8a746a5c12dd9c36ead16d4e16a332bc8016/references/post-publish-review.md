# 发布后复盘与下一版测试

## 1. 先留存原始证据
- 保留截图原件/来源与采样时点，按截图原名、单位和精度转录指标；同时分别记录发布日期、距发布时长、发布版本及实际发布片长。不要把截图时间当发布日期，也不要把制作稿或资源索引中的片长当作已发布版本片长。
- 未标名称的图标指标逐列记为“未标明指标1/2…”并保留顺序和图标描述，不猜是点赞、收藏或转发，更不合并成“互动数”。裁切、未显示、不可辨认分别标注，缺失不记作0。
- 把观察记录与解释分开。账号数据、截图及具体素材身份留在本次任务中；写入可迁移技能的只应是流程和必要的泛化例子，不积累用户账号数据或Library ID。

## 2. 核对可比性，再描述差异
- 尽量对齐发布后约24小时的观察窗口；并记录平台、题材、目标受众、流量来源及其未知项。窗口不同或来源不明时，说明只能作粗略描述；不要把跨题材、跨受众的两条视频当作控制实验。
- 原样列播放量、3秒留存/播放率、平均观看时长、完播率等可见指标，并沿用平台名称，不擅自互换指标定义。百分率之差用“百分点”；平均观看时长之差用秒，不能混淆相对增长与百分点。
- 样本少时把差异当作测试线索，不宣称统计可靠、平台偏好或因果关系。不得仅凭两条小样本认定某种开头、语速、题材或剪辑导致表现变化。
- 平均观看更久不等于中后段内容更好；平均时长与完播率均受总片长及受众影响。先核实实际发布版本/片长；要定位某一秒或某一段的流失，还需留存曲线并对照发布成片、旁白与画面。不能从总体均值反推逐秒曲线；缺材料就明确诊断边界。

## 3. 优先检查前3秒，但不要套公式
- 先看前3秒观众实际看到、听到什么，是否有进入具体内容前的等待。没有成片或开头素材时，只能提出待验证假设，不声称看过或已定位问题。
- 按题材尝试真实结果或反常画面作为钩子，尽快说明具体使用场景或对观众的收益，再接实际操作。画面要对应当下旁白，承诺要能由后文兑现，不用无关奇观或夸张效果骗停留。
- 把这当作开头的可选设计与优先测试方向，不强制每条使用同一公式，也不要求每秒切镜。保留有价值的连续操作、解释和已批准品牌风格；先比较开头，再决定是否有证据改动中后段。

## 4. 每轮集中检验一个主要变量
- 先写一句可证伪的假设和一个主要测试变量。把开头、语速/节奏、素材呈现分轮测试，尽量保留题材、正文内容、长度、发布时间/观察窗口等其他条件；无法控制的差异明确列出。
- 开头轮可优先观察平台对应的3秒指标，并同时留意平均观看和完播是否牺牲；不要仅追求短期停留而削弱后文兑现。语速/节奏轮保留尾字、可懂度和嘴型；素材轮保留已批准的主画面、字幕安全区和片尾规则。
- 留下基线、版本标识、具体改动、预定观察窗口和评估指标；保留旧版与优质内容。下一轮只根据新证据决定保留、再试或撤回，不把一次改动永久固化为全片规范。
- 复盘按“可见事实 → 可比性/缺失 → 有限假设 → 一个优先测试”交付。获取更多截图、重剪、付费生成、正式发布或持续监测仍遵循本次授权，复盘本身不授权这些动作。
