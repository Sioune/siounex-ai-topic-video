# 系列选择与视觉验收

本页适用于每支新片、已有片换模板及终审；旧实例的固定素材ID、时段和视觉样式不是新任务默认。规则不代替实际部署或单条成片验收；当前两套的本人认可与执行范围见下文。

## 往期：最近已发布3期
- 建立有来源的发布档案：作品ID、标题、真实发布时间（含时区）、发布状态、发布记录/用户确认、封面与文件身份。采用真实发布时间，不按文件修改时间、入库时间、工程序号或文件名排序。用户确认可作来源，但别冒称已核验平台文件。
- 每任务筛除当前片、草稿、待发布、已取消或无法确认已发布的记录，按发布时间倒序取最近3期，持久化选择及档案快照。缺时间或发布状态可能改变前3名时先补记录，不猜顺序或沿用旧ID。并列时间无法判定且影响入选时查证。
- 确知总共不足3期时用实际已发布数量并说明；未知是否还有更近期作品时不能把“现有三条”称为“最近三期”。不复制卡片凑3期。正文中一次单轮及退出后回真实进度规则保留；刷新/重试不偷偷替换任务已锁定的往期，需更新时明确刷新档案与版本。

- 推荐标题必须与发布库中该作品实际发布标题逐字一致，按作品ID、发布记录及文件身份关联；禁止AI另造短题、概括代替原标题或随意改名，保证观众能找到原作品。当前任务有用户授权的最新三期名单时锁定该名单并核对发布库，不擅自换片；名单或原标题不明时补核，不从封面文案/文件名推造。
- 推荐区栏目名、原标题、说明须有统一的层级、对齐和间距，充分利用横向留白，优先单行完整原标题；不得为单行而缩到手机不可读，也不得截断、省略或改写原标题。确实放不下时调整布局或完整换行，避免文字挤堆，保留手机安全区；常驻章节文字与揭亮全过程不得裁切。以最终导出手机尺寸截图核验，不以工程坐标代替视觉检查。

## 模板：制作浅深交替，片仓按早晚分类（2026-10-22）
- 本人已认可「晨光浅底」与「夜间深底」及两版共同的字幕留白修订。正式模板键为 `morning-light@1`／`evening-dark@1`，运行器为 `morning-light-v1`／`evening-dark-v2`，共用 `approved-node-stage-v2`。旧银色样式仍只作历史参照，不能借浅底需求恢复它。
- 新制作读取所有者已持久化的交替记录，按浅色、深色交替选用；保存模板ID、精确版本、`method=alternating_approved`、整数`production_sequence`和本次选择依据。分类为 `template-publishing-slot-v1`，其中 `timezone=Asia/Shanghai`、`time=08:00或18:00`、`selection_sequence`与制作序号一致、`policy=morning-light-evening-dark-v1`；不含预定发布日期。同一请求恢复、失败重试、本人换声与重新导出沿用已保存选择，不重复消耗交替序号。并发新任务须串行领取交替结果，不能同时读旧记录而选成同一色。旧随机选择机制与已锁定工程仅保留历史身份，不作为新制作默认。
- 制作时不预订未来具体发布日期。两次人工审核仍为普通配音版首审、本人声音版二审；两次通过后将完整发布包冻结入仓，再依据包内的真实模板身份归为早间／晚间类别。模板整体获认可不代替任何一条作品的内容、声音和最终人工审核。
- 北京时间08:00只取浅色正文＋原v5深色片尾，18:00只取深色正文＋原v5浅色片尾。对应类别内按原入仓批准顺序FIFO，提前准备和正式提交接续同一package_id；对应类别缺货就保留空档，不拿另一类别顶替，不在发布时间改色、换片或重新渲染。旧冻结包不因这次规则升级而重做、重审或伪造新模板标签。
- 两套均保留完整1024×576横屏区、76px手机大字幕和底部380px安全区。v2共享位置为主画面y474、字幕中心y1136、章节y1228、往期卡y1304（高236）；深浅配色分别锁定，不能只换背景而留下不适配的字幕、品牌字或往期卡颜色。
- 继续分别保存功能验收、技术验证与本人审美认可依据。用户另提新方向时保留稳定候选ID，修改显式递增版本；待审方向不自动进入已认可库，不擅自替换本次两套已认可模板。
- 本技能 `assets/day-night-templates-v1/` 保存当前政策、两项模板目录快照、布局身份和正式源码恢复索引。索引路径以当前正式源码仓库根目录为基准；跨机须实际取得对应SHA源码／归档、原片尾及字体依赖。它不是完整可执行素材包，不可把本机目录或旧 `assets/unified-v9-runtime/` 冒充新模板运行包。

## 字幕、片尾与核心3秒
- 读取此前用户认可的手机可读字幕基线，记下参照片版本、字体、归一化字高、描边/对比度、行数与安全区。在同尺寸手机画面并排比较；新模板不能让字幕变小，必要时调整其他布局。720宽约48px是旧基线参考，不能替代找到实际认可版本。基线缺失标待查，不伪造通过。
- 两套固定复用原v5反向明暗片尾：浅色正文配深色片尾，深色正文配浅色片尾。两版原件均119帧、30fps、3.966667秒，AAC原声3.95秒；预算可预留4秒，保留全部原帧、原速和完整原声，正文换声与BGM不作用到片尾。其他获明确授权的混合主题依其实际收尾背景选择；旧冻结片尾保留原版本，不另造变体。
- 完整正文初剪完成后通看整片，挑语义最核心、真实连续3秒，写明它兑现的核心结果、动作或反差以及为何值得前置。记录源文件精确版本/哈希、源入出时码、它在完整片前置前的位置和最终开头映射，留完整片对应段及开头片段以核对。
- 最大运动量、最高亮度、文件名highlight、已有开场片段或随机截取都不是语义选择证据。保留真实连续性，不凑帧、不拼造结果；软衔接需实际连续播放检查。不重复旁白/音频，不机械延长片长。跨源速率映射记录速度；源时长可随变速不同，但最终高光实播为连续3秒。

## 可执行QA
这是一项完整系列终审检查，含成片后的证据，不是阻止首次制作的前置门。创建检查JSON并运行 `python scripts/qa_series.py 检查.json`，自测用 `--self-test`。字段示例与校验见脚本：publication_records、history_ids/current_id、catalog_verified、template、subtitle、outro、highlight。新交替记录在template中提供selection_method、production_sequence及publishing_slot，片尾记录提供version=v5与frames=119；历史random记录继续按原结构核验。脚本只检查记录一致性，不联网确认事实，不代替看图、听审、交替记录或片仓分类核验；不能为了过检编造字段。blocked 表示不能标为已验收/已认可，不阻止当前用户已授权的待审设计、制作或预览；按具体缺项阻止依赖该事实的步骤，独立工作继续。

逐条完成并保存证据：
1. 用发布档案独立重算前3期，对照当前任务卡片ID/标题/封面，确认排除当前片和未发布；有本次授权名单时核对锁定名单，逐字比较实际发布原标题，并检查推荐层级、横向留白、手机安全区与章节无裁切，记录不全则待补。
2. 对照认可证据及可恢复模板身份，确认新制作已按交替记录锁定ID/版本、序号与类别；刷新、失败重试和换声前后检查不变。旧冻结工程沿用原选择，不追补新的交替序号。若本次是指定待审新方向，标为待审，不伪称来自认可库。
3. 对照上一支与本片手机截图，分别记录背景、章节条、filmstrip改善点与未解决处；功能通过、技术通过与审美依据分别报告；本次两套可引用2026-10-22真实认可，新变体未经本人确认仍属待审。
4. 同手机尺寸比对字幕归一化字高、最长两行、描边/对比度与安全区；不能靠工程字号更大掩盖最终缩小，或以模板空间不足接受更小字。
5. 在成片接点核对主体与原片尾明暗相反，原v5资产身份、119帧／3.966667秒及完整原声正确；旧冻结工程按其原绑定核验。
6. 对照源时码、完整片对应段及最终前3秒连续播放，核核心内容而非仅运动强度，并检查软衔接和声音无重复。证据缺失不可标完成。

任何预检零错误都只代表记录通过；必须做真实视觉及音画验证。素材、历史档案、认可模板或字幕基线缺失时继续独立工作，相关项留待补，不把技能/网站规则保存当成成片验收。
