# 系列模板与版本绑定

同一 owner-only Site。无数据库迁移：模板目录、发布时间证据和不可变任务选择存于现有 app_state；选择与来源导入回执追加至 production_reviews。原收藏、排除、已制作、稿件、审核及媒体操作均不改写。历史代码回滚不得恢复旧数据库快照。

工作台显示实际模板归档和预览。本人可写理由指定候选，或在有完整资产、真实运行器和本人认可依据的模板池抽签。种子、模板全文/哈希、最近三期来源及精度、安全区、字幕76px和已有反色片尾选择一次保存。刷新、断线、重复请求不重抽；修改需要明确理由、当前选择ID和版本/模式epoch。并发修改只有一位成功。执行中、审核中或有效媒体租约不能换参数。模式变更保留旧选择，须本人显式重确认。已绑定任务不会随模板库修改而换模板。

保存当前模板为待审新版本会复用其真实归档资产，并记录本人的说明；不会自动认可或假称新图形已制作。本人认可另存新版本。旧版本保留。当前只有一个完整且认可的深色安全区版本，界面明确不足以保证多支视频视觉差异。商务候选和修正前的候选保持待审，不随机采用。当前Claude独立制作任务禁止改动。

最近三期按真实发布时间区间排序，排除当前任务及未发布作品。分钟、约时和只有日期的证据保存原精度；重叠、缺日期、档案未确认齐备、不足三期均显示缺口。不得拿创建日期冒充发布时间。导入证据不修改原 production_data_videos 的 published_at。

新任务和实际Codex生成/独立审核提示词带上述保存参数。运行器实际消费绑定哈希、种子和历史顺序；1080画布字幕76px，正文关键元素距底部至少380px，连续章节揭示、胶片条全局时钟和宽版往期推荐。现有稿件的冻结技能不换版；新的完整a21快照用于后续新任务。媒体准备稿须绑定真实选择；后验关联须明确说明，不得把服务器后来生成的ID伪装为早先渲染输入。

隔离SQLite与实际HTTP路由/React组件检查覆盖权限、同源、防重放覆盖、并发选择、重新读取、模式epoch、历史目录版本及原审核不变。运行器几何和字幕检查保留原台词/时间。实际66.6秒准备稿全量音视频解码、90帧源画面对照、1878源帧不丢失、120帧归一化原片尾RGB逐帧对照和AAC字节保留已通过。技术结果不等于完整看审或听审，不等于本人质量批准。

当前环境浏览器控制启动失败（Windows平台目录缺失）。本轮不宣称完成实际手机点击/返回导航验收；原导航实现保持，接口与组件检查有独立证据。执行器仍需人工启动。旧暂停操作须本人决定，媒体准备稿不恢复操作、不开始正式节点、不批准视频、不外部发布、无新增付费调用。
